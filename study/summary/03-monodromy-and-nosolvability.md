## 1. 用大白话说这条结论

中学就学过：二次、三次、四次方程有求根公式（只用加减乘除和开方），**五次以上一般没有**。
判断"有没有"，靠的是方程的**伽罗瓦群**是否**可解**。

机械臂的逆解方程（给定末端位姿，求关节角）也是一组多项式方程。我们想回答：

> 这台六轴臂的逆解，**能不能用关节角的四则运算和开方写成公式**？

数学上，"逆解方程在函数域上的伽罗瓦群 = 单值化群"（Harris 1979）：
让机械参数绕"折点"转一圈，解之间会**互相交换**；把所有这样的交换收集起来生成的置换群，
就是伽罗瓦群。**这个群可以用数值方法测出来**。

```
参数平面（例如"腕部偏置"这个参数）
        ┌───────────┐
        │   ○ s*    │   ← 折点（fold）：两个解在这里相撞
        └───────────┘
   绕它走一圈 ──►  解 1 与解 2 交换  ⇒  记一条"对换边"
```

## 2. 实测链条

### 2.1 绕折点的对换（基本观测）

* `exp37`：复平面上绕折点 `s* = 0.718354` 的小圆（半径 `1e-3`），**两个旋向**都把合并的根对互换；
  端点匹配 `2.6e-10`、虚部残留 `1e-17`；远根不动、空圆负对照不动。
* `exp45`：独立方法（绕 fold 的回路 + 纤维匹配）复核，干净片段一致。

### 2.2 全纤维与边表

* `exp38`：在 `s = 1` 处**确定性构造 16 根**（10 实 + 6 复；复根由消亡 fold 对绕上半平面小弧追踪而来，
  残差 `1e-15`）——达到 Raghavan–Roth 上界。
* `exp40`：复 `s` 平面普查（2000 种子）找复分支点。
* 合并 7 个实 fold 的对换 + 复分支点的对换，得到**对换边表**。

### 2.3 群判定

* `exp44`：6 元分量的 5 条边，**显式闭包验证阶 = 720 = |S6|**，且含 `A6`。
* 由"`S6` 含单群 `A6` ⇒ 不可解"、"可解群的子群可解"⇒ 单值化群不可解 ⇒ **无根式解**。
* **加强（kimi 第 11–12 轮）**：新增第 11 条边（`1.047164` 的 fold；旧读数"两条 strata"是**环面伪影**——
  两个代表在 joint 4/5 上恰好相差 `2π`），图分解为 `[6, 6, 1, 1, 1, 1]`：
  **两个 6 元分量各自闭包到 `S6`** ⇒ **双份独立证据**。

## 3. 这句话**不**意味着什么（两条限定，务必一起引用）

1. **不排除"闭式消元"**：Raghavan–Roth 的 16 次单变量多项式**是存在的**（我们甚至构造出 16 根）。
   结论的含义是"**不可能做得比数值求解那个 16 次多项式更好（只用四则运算和开方）**"。
2. **这是复侧的结论**：它谈的是"复单值化群 = 伽罗瓦群"，与**实**侧的 cuspidality / aspect 结构**正交**。
   实侧的结构由见证路径直接测量（见 `01`、`02`），两者互不推出。

```
        可解性（复侧，代数）                分支结构（实侧，几何/拓扑）
   ┌───────────────────────────┐      ┌───────────────────────────────┐
   │ 单值化群 ⊇ S6 ⇒ 无根式解  │      │ aspect / 唯一性域 / cusp       │
   │ 由对换边表 + 闭包判定      │      │ 由见证路径 + 事件表 + 相切实测 │
   └───────────────────────────┘      └───────────────────────────────┘
              ↑ 二者互相独立：3R 玩具臂是"分支复杂(有 cusp) 且 根式可解"的正见证
```

## 4. 仪器与失误（这一段的价值在于"怎么才敢信"）

* **每一条对换都配对照**：空回路（不绕任何折点）必须读出恒等；远根必须不动；两个旋向必须给同一个对换。
* **复延拓三坑**（都已归档）：复参数写进实数组会静默丢虚部；回路起点角必须匹配纤维的实侧；
  实牛顿过不了 fold 的合并点（要绕上半平面小弧）。
* **跳盆污染**：回路测量在途中折点的"弧顶"会被牛顿跳盆污染（空回路探针读出别家的边）。
  这一条在最近一轮又被独立撞见一次：**持续多个采样的"合并"是跳盆，不是真相撞**（见 `01` §6）。
* **环面去重**：两条"不同"的根在环面上可能只差 `2π` 的整数倍（kimi 的 `exp40` 曾因此把一个 fold
  记成两个）。凡涉及解的"去重/相同"判断，都要用**环面距离**。

## 5. 结论的强度与边界

| 项目 | 状态 |
|---|---|
| "绕折点的对换"是测量出来的 | ✓ 两种独立方法（根对追踪 / 全纤维复环）在干净片段一致 |
| 边表 → 分量 `[6,6,1,1,1,1]` | ✓ 11 条边；两个 6 元分量各含 `S6` |
| "不可解 ⇒ 无根式解"的传递 | ✓ 纯群论（`S6` 含 `A6`，子群可解性） |
| 全单值化群是否是完整的 `S16` | **未决**（对换图还在生长，四个孤立根未接入） |
| 复分支点普查是否饱和 | 5000 种子与 2000 种子给出的点集**相同**（14 个）⇒ 当前种子分布下饱和；要更多点需换分布 |
| 3R 的 cusp 检测器交叉验证 | ✓ 独立工具在 3R 基准上报"无回转点"→ 后来按分量分析找到两处相切（见 `02` §5.3） |
