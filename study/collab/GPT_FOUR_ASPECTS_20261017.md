# 当前 3R 的四个 aspect：精确计数与下一步分工

2026-10-17，GPT。承接 `GPT_NEXT_GATE_20261017.md` 的非 cuspidal 证明。本轮只新增此文档，不触碰正在修改的 T5b/T4 文件。

## 1. 从“至少四个”升级为“恰好四个”

**定理**：对 `cuspidal3r.DEFAULT_ROWS/DEFAULT_TOOL` 的精确直角模型，取关节空间 `Q=(S¹)³`，位置 Jacobian 的正则集恰好有四个连通分量，分别由

```
(sign(sin v), sign(g)),
g=2 sin u+(3/2)sin v cos u+(3/2)cos v
```

标记。每个分量微分同胚于 `S¹×(0,1)²`。这里不把有限关节限位盒与环面混同。

### 证明

已知 `det J=(3/2)sin v*g`。所以奇异集是

```
Σ = {sin v=0} ∪ {g=0}.
```

注意是**并集**，不是要求两个因子同时为零。它们的交点对应此前分析的更高退化点。

删除 sin v=0 后，v 在两个开区间 `I+=(0,π)`、`I−=(π,2π)` 中。令

```
b(v)=(3/2)sin v,
r(v)=sqrt(4+b(v)²),
θ(v)=atan(b(v)/2),
φ=u+θ(v) mod 2π.
```

因 cos θ=2/r、sin θ=b/r，这个光滑坐标变换把 g 写成

```
g = r(v)sin φ+(3/2)cos v.
c(v)=−(3/2)cos v/r(v),     |c(v)|≤3/4<1.
```

令 α(v)=arcsin c(v)，取主值。对每个 v：

```
g>0 : φ∈(α(v), π−α(v)) mod 2π,
g<0 : φ∈(π−α(v), 2π+α(v)) mod 2π.
```

两者各是一条非空开圆弧，端点光滑依赖 v。用开圆弧两端之间的归一化参数 t∈(0,1) 表示 φ，再用 v 所在 I± 的归一化参数表示 v，即给出每个符号区域与 `(0,1)²` 的显式微分同胚。q1 独立取 S¹，所以四个符号区域分别与 `S¹×(0,1)²` 微分同胚。

四个区域都非空、连通，区域间任何路径必改变至少一个连续非零因子的符号，因而必须穿过 Σ。故它们恰为四个 aspect。证毕。

这不是通过网格数分量得到的结论，没有分辨率参数，也没有对采样饱和的依赖。

## 2. 每个 aspect 上 FK 实际上全局单射

上一份证明已说明：固定位置后，每个符号标签至多一个正则逆解。现在每个标签区域恰好是一个 aspect，因此位置 FK 在每个 aspect 上全局单射。

由于该处 Jacobian 可逆，FK 是局部微分同胚；结合全局单射，它是该 aspect 到其开像的微分同胚。故在这台具体非 cuspidal 模型上，每个 aspect 本身就是一个单射域，不需要依赖网格再把它拆成若干局部逆解片。

注意这没有推广到 SR5，也没有断言整个工作空间上的各 aspect 像互不重叠；不同 aspect 的像恰可重叠并产生多解。

## 3. 原 3R 的价值仍在，但角色应该改变

建议保留当前 3R，明确改成以下用途的精确基准：

- 四 aspect 的解析连通分量 oracle；可直接检验网格连通算法是否错误合并。
- 正则纤维中“符号标签→唯一逆解”的解析 oracle。
- 源芽 `(x,y)→(x,y⁴+xy²)`、共享临界值、实临界像半支的退化例子。
- 根式可解但**非 cuspidal**的对照组。

不应为了恢复旧故事而修改 DEFAULT_ROWS 并覆盖旧结果。新模型应使用新名称、新参数和独立记录。

### 给 T6 执行者的确定性扩展

1. 独立核对以上坐标变换与两条开圆弧表达式。
2. 直接以两因子符号建立旧网格每个节点的解析标签，输出每个网格分量包含的标签集合。
3. 标记连接不同标签的网格边，并记录是哪个因子变号；相同标签端点也不能自动证明整条边无奇异。
4. 使用解析标签作为回归 oracle，而不把更密网格输出当新的真值。
5. 原 FK 中的理论直角与浮点 cos(π/2) 近似分开描述；近零符号数值上记未决。本文定理针对明确的精确模型。

## 4. 是否另选真正 cuspidal 的模型

**建议另选，但作为独立支线，不阻塞 T4。** 当前模型的“可解且 cuspidal 正见证”已撤回，研究总览可以暂写缺少该实例，不需要立刻填满。

候选验证任务 T7（供用户转交，本文未自动启动）：

1. 从原始论文或作者资料选取一个明确给出结构、DH 约定、参数及非奇异换解证据的模型。保留出处、页码和参数，不凭示意图猜 MDH 表。
2. 独立核对轴线结构与 FK，再核对标准 DH/改进 DH、工具行、关节零位的转换。单纯全秩不足以证明建的是文献中的那台臂。
3. 先交付两个不同构型、相同目标位置、以及连接它们的完整无奇异路径。存在与同位置条件、构型不同、全段非奇异是三项独立验收。
4. 用解析路径界或完整认证确认路径；只有数值证据时明确标注。普通 cusp 候选也不能只凭图像或相切判断。
5. 根式可解性需有适用于该模型的消元/恢复公式或明确的适用定理；不能仅因同为 3R 就省略这一检查。
6. 先验证一个候选，不开展大规模随机选型。若几何约定无法对齐，提交失败原因并停止该候选。

“可解且 cuspidal”的一个例子能否定“根式可解 ⇒ 非 cuspidal”；它本身不能证明任意含义下的全面“正交/独立”。总结应写具体被否定的蕴含。

## 5. 对 T4 主线的一个结构提醒

固定 SR5 的复关节空间 `(C*)⁶` 是不可约的。若已证明 FK dominant、generically finite，并限制到非空有限 étale 底域 U，那么其原像是不可约空间的非空 Zariski 开集，因而复解析意义下连通。由覆盖空间路径提升，**完整单值化群在完整一般纤维上作用传递**。

这是一条带明确前提的结构结论，不是说 Gate A 找到的少数回路生成的子群必须传递。测得子群分成 `[6,6,1,1,1,1]` 完全可能只是回路采得不足；不能直接读成完整逆解覆盖有这些不可约分量。

它也不意味着必须补齐所有边才能证明不可解：只要认证出的子群已经不可解，主命题即可成立。

## 6. 两个表述修正

- “det 的两个因子在奇异集上同时归零”应改为“至少一个归零”；非奇异集上则二者均非零。
- 2000 个位姿无注入性违例是数值交叉验证；全局注入性来自二次式导数符号与 u、q1 恢复公式的证明。证明与数值检查应分别列出。

另：前轮实解析正规形证明中的 `sqrt(|K|)` 在 K<0 的邻域仍合法，因为 K 不变号，`|K|=−K` 是正的实解析函数，符号由 ε1 单独保存。若换为复解析表述才应改用选定的复平方根分支；不要把实解析证明误改成必须使用纯虚坐标。
