# 固定 SR5：五根运输、15 条提升与局部最优性

## 结果

精确群论计算从现有数值置换提取出一个更小的认证目标：

* 五根集合 `T={4,6,8,10,13}`；
* 两个在 T 上作用的回路：d，以及 `g=a^-1 h a`（实际执行顺序 a、h、逆 a）；
* 只需 a、d、h 各五根的认证提升，共 **15 条不同的“基础回路/起始根”提升**，代替旧六根三环的 18 条。

新目标的实际单值化作用**仍未认证**。本轮完成的是准确的充分条件、枚举与有限模型中的下界，不是固定臂不可解性的升级。

## 1. 从“保持一个集合”改为“在两个集合之间运输”

令 `U={1,4,8,10,13}`。归档的作用给出

```
a:T→U : 4→4, 6→1, 8→8, 10→10, 13→13

d:T→T : 4↔6, 8→8, 10→10, 13→13

h:U→U : 1↔8, 4→10→13→4.
```

认证上面十五条提升及其端点身份即可；不要求 a 在 T 或 U 上是自置换。沿 a 的逆路径，从 U 返回 T，用的就是同一批五条已认证轨迹的反向，不需要再独立计算或假设 a 在完整纤维上为对合。

这时实际回路 `g=a^-1 h a` 在 T 上的限制为

```
p=d|T=(4 6),
q=g|T=(6 8)(4 10 13).
```

于是

```
q³=(6 8),
p=(4 6),
q² p q^-2=(13 6),
q⁴ p q^-4=(10 6).
```

四个纯对换的边构成五点星形树，所以限制像是 S5。脚本另外枚举闭包为 120、导群阶为 60（A5 完美），因此不可解。

只读五根限制像时，应说真实单值化子群有不可解的 S5 **像**，不能据此断言完整单值化群一定分裂出一个 S5 子群。不可解像已足以否定整个群可解。

## 2. 为什么从六根到五根是合法的

旧方案要求 a、d、h 同时保持六根集合。新方案只要求 d 保持 T，h 保持 U，a 给出 T 与 U 的双射。这个有限“换图”结构就足够定义两个实际目标回路在 T 上的作用。

证书仍要覆盖每条目标路径的全部参数段，保持全部极点、旋转假根排除和严格拼接条件。公共基点需要识别 `T∪U` 的六个根，现有 C1 可以复用；五根说的是最终群作用的集合，不是声称只需五个基点盒。

若未跟踪根的临界值经过目标路径，仍使用原 Gate C 规范的桥接：严格管道及匹配在足够小的共同目标扰动下保持，再在真正有限 étale 覆盖的开集中取路径。a 的扰动与逆 a 必须成对保持为逆路径，公共端点/五根运输一起保持。这个压缩不免除该桥接论证。

## 3. 明确的成本账本

| 基础回路 | 旧六根方案 | 新方案所需起始根 | 省去 |
|---|---:|---|---|
| a | 6 | 4,6,8,10,13 | 1 |
| d | 6 | 4,6,8,10,13 | 1 |
| h | 6 | 1,4,8,10,13 | 6 |
| 总计 | 18 | 15 | 3 |

这是 **16.7% 的条目减少**，不是已测的运行时间减少。昂贵的根 13 仍需三环全程认证，故不能期望这个结果单独改变此前成本的数量级。

若把复合路径简单展开并重复计算，反而可能增加工作。应保存基础提升并复用反向、重复经过的轨迹和基点匹配。

另一个简洁但较贵的见证是 `(ad)^2=(1 4 6)`、`h²=(4 13 10)`：两三循环只共享 4，生成五点上的 A5。展开并去重后需 16 条基础提升。它适合解释群论，但不是本轮选出的最佳认证目标。

## 4. 有限运输模型内，15 条是最优的

本节下界的模型限定如下：

1. 中间根标签取自已有六根 `S={1,4,6,8,10,13}`；
2. 每步始终运输五个不同根；
3. 使用已有 a、d、h 和它们的逆路径，复用已认证提升；
4. 从这些完整五根运输所诱导的有限置换作用推出不可解性。

每使用一个基础回路，至少需要五条提升。任意两个基础作用在 S 上生成的群均可解：`<a,d>` 阶 6，`<a,h>` 阶 18，`<d,h>` 阶 48（脚本逐级计算导群到 1）。因此不足十五条只能使用至多两个基础回路，不能在这个模型内强迫不可解性。上面的十五条方案达到下界。

这不是所有可能认证方法的全局下界。变动跟踪根数、引入新回路、使用额外几何条件、单独认证局部分歧或非置换型证据，均不属于这个模型。

## 5. 全部 216 种十五条方案与根 13 障碍

十五条预算意味着每个基础回路恰好认证 S 中五根。分别记遗漏根为 o_a、o_d、o_h，共 `6³=216` 种选择。

每个五根集合可由“遗漏的那个根”标记。认证 g 的五条提升，给出一条可逆换图边

```
o_g → g(o_g),
S\{o_g} → S\{g(o_g)}.
```

在这个六顶点、三条边的图中，一切可以复用现有数据构成的五根闭运输，都来自某个连通分量的闭游走。选一棵生成树把各顶点搬到同一个根图，每条边给出一个闭运输生成元。枚举其五点置换闭包并检查导群，就检查了全部闭游走，不是只抽样几个短单词。

结果：216 种中只有以下四种产生不可解作用（均为 S5）：

```
(o_a,o_d,o_h) = (1,1,6), (4,4,6), (4,6,6), (6,1,6).
```

所以在这个最省条目、固定五根宽度的模型内：

* h 必须遗漏 6；
* a、d 只可能遗漏 1、4、6 中的某些标签；
* **没有任何不可解方案能省去 a、d、h 上的根 13，也不能省去根 8、10。**

因此“用更小群论见证跳过最贵根”的希望，在这个明确模型内被否决；但中间集合变化确实省下了三条便宜的提升。这是本轮搜索的重要边界。

## 6. 为什么只看到两个相交三循环不够

如果两条置换在五点上分别为纯三循环且支撑只交一点，它们确实生成 A5。但仅认证各自三条循环轨迹，尚未检查另外两个点如何移动，不能套用该结论。

反例取四面体的六条边，令顶点上的 `(0 1 2)`、`(0 1 3)` 诱导边置换。每个边置换包含两个三循环。各选一个三循环，其支撑恰交一条边；然而它们生成的完整边作用是 A4，导群阶依次 `12→4→1`，可解。

脚本保存了这个六点反例的全部置换。它甚至只比五点多一个未观察点，因此不能以“只遗漏很少几根”忽略闭合性。

```
python3 -m study.exp75_minimal_group_witness
python3 -m pytest -q tests/test_minimal_group_witness.py
```

`exp75_minimal_group_witness.json` 保存全部 216 个遗漏组合、每个连通分量的导群阶序列、新旧账本和反例。原始数值回路归档只提供候选置换；这些有限群计算本身是精确的。

后续认证可直接改为本节十五条目标。数学上的下一突破更可能来自“为什么这些几何路径上的提升保持正则”的更强结构，或重新设计回路；继续在这三条路径的固定五根运输模型里删条目，已到下界。SR5 严格不可解性仍等待实际路径证书。
