## 1. 第一项实际发现：原始浮点目标并非精确位姿

把 exp68 的 target0 旋转块每个 float 当作精确二进制有理数，精确计算得到 `RᵀR != I`。浮点 Frobenius 缺陷约 `2.22e-16`；这虽然工程上可忽略，却意味着直接把这九个数当精确旋转目标，12 分量完整 FK 方程可能根本没有精确零点。

因此 Gate C 必须先冻结合法数学输入。

### 已完成的冻结

`exp69_exact_gate_c_model.py` 写出 `exp69_exact_model.json`：

- SR5 连杆旋转是精确带符号置换矩阵，长度是配置文件中的短有限十进制有理数，例如 0.136=17/125；机械参数不再变化。
- p0 的三个归档 float 解释为精确二进制有理数。
- 从归档旋转数值计算 Cayley 参数 w，随后把计算出的三个 float 固定为精确二进制有理数，定义

```
W=[w]×,
R*=(I+W)(I-W)^(-1).
```

所得 R* 是**精确有理**矩阵，符号验证 `R*ᵀR*=I, det R*=1`。与归档 R 的浮点 Frobenius 距离为 `2.6294654400e-16`。

三条路径统一使用这个新的精确旋转 R*，旧轨迹只作为近似根种子。这不是未经证明地把证书迁移回原始非法浮点旋转；目标是直接认证新的合法回路，证明的机械臂仍是同一固定 SR5。

路径参数使用归档节点的精确二进制有理实部/虚部，**定义为节点之间的分段直线**。不需要认证理想圆弧或分支点中心确实为 fold；任何合法闭回路给出的真实置换都可以作为生成元。

## 2. 泛有限性不再只是一个假设

取代数关节变量 `z_j=exp(iq_j) ∈ C*`，使用

```
c_j=(z_j+z_j^(-1))/2,
s_j=(z_j-z_j^(-1))/(2i).
```

FK 是 `(C*)⁶→SO(3,C)×C³` 的 Laurent 多项式映射。exp69 在精确点

```
(z1,...,z6)=(1+i,2+i,3+i,4+i,5+i,6+i)
```

对六个输出函数 `p` 与 `vee((R-Rᵀ)/2)` 的六乘六导数，算出了**精确非零有理复行列式**。矩阵与行列式完整存入 JSON，不靠浮点阈值判断非零。

因此 FK 在该点秩 6。源与目标均为不可约六维复代数簇，故 FK dominant 且 generically finite；特征零下泛可分。存在非空开集 U，使限制是有限 étale 覆盖。该证明不需要先证明次数为 16。

## 3. 严格不可解性只需跟踪六根

从归档的 a,d,h 检查到，集合

```
S={1,4,6,8,10,13}
```

在三条置换下保持不变。限制作用为

```
a|S=(1 6),
d|S=(4 6),
h|S=(1 8)(4 10 13).
```

前轮四个共轭字已给出 S5；再取 `h²(dad⁻¹)h⁻²=(1 13)`，将第六点接入，限制生成群其实为 S6（精确群计算阶 720）。**证明不可解只需其中 S5，不要求升级目标。**

### 群论措辞的必要区分

只认证六根时，得到的是实际单值化子群 H 在这个不变子集上的**像**不可解。因为可解群的同态像必可解，所以 H、进而整体 G 不可解。

这足以推出固定臂的逆函数不能全用根式表达，但**不能仅凭限制像就宣称 G 必有一个分裂嵌入的 S6 子群**。全 16 根认证的版本可保留前轮的 S5 子群论证；六根路线改用“不可解像”这一更弱但足够的命题。

### 其他根的奇异值怎么办

六根逐段有严格正余量的认证，会保证这六条局部分支在各自管道内正则，未跟踪根可能仍在某些目标点奇异。不能把“六根正则”直接写成“整条目标路径位于 U”。

补桥如下：有限个严格收缩证书在目标参数小扰动下仍成立；同一基点的六个根盒、拼接包含关系也可保持。可在共同基点附近选取属于 U 的基点，并将三条闭路径作任意小的、保持共同基点的扰动，使其避开 U 的代数补集。复代数真子集实余维至少 2，分段路径可用一般小扰动及小绕行避开。经认证的六根提升在这种扰动下保持其匹配标签。

于是 U 上真实单值化的某个子群在这六根上的作用就是上述三置换。这个论证需要认证给出**严格余量**和有限个管道；不是仅有零余量的端点等式。若执行方不愿处理这一步，可选择认证全部 16 根并另行证明纤维完备性，但那不是最省的证明路线。

小扰动发生在固定 SR5 的目标位姿空间，绝不改变机械参数，因此不重现 Q27 的旧缺口。

## 4. 可认证的六维平方系统，及排除假根的条件

由精确 FK 得到 R(z)、p(z)，令 `S(z)=R*ᵀ R(z)`。对于路径参数 λ 定义

```
F(z,λ) = [ p(z)-p0-λd ; vee((S(z)-S(z)ᵀ)/2) ] = 0.
```

这是六个复有理方程、六个复未知量；仅含 Laurent 分母 z_j，不使用反三角函数，不需要 12 分量最小二乘认证。

**不可省略的附加条件**：每个认证管道排除 z_j=0，并认证

```
|trace S(z)-3| < 4
```

在整管道成立（可换成更强的 `||S-I||<2` 型条件）。

证明其必要性：skew(S)=0 本身也允许半周旋转假根。但在本模型中恒有 SᵀS=I、det S=1；若又 S=Sᵀ，则 S²=I，故可对角化且特征值±1，trace 只能为 3 或 −1。上述条件排除了 −1，故 S=I。因此管道内 F=0 与完整 FK 目标方程等价。

区间评价须用精确有理 R*，不能把 JSON 系数转成 float 后再声称精确。中心点可以是 NumPy 得到的 `exp(iq)` 近似：它们只用于选盒，随后按精确二进制有理数读取，完全不需要假设这些近似指数计算已被认证。

## 5. 逐段存在、唯一与正则性：一个足够的收缩判据

把六复未知量实化为 x∈R¹²。对一段参数

```
λ(t)=(1-t)λ0+tλ1,  t∈[0,1]
```

记实化方程为 f(x,t)。选盒 `X=c+[-r,r]¹²`（先用统一半径），B 为近似逆矩阵但其元素按精确有理数解释。定义

```
T_t(x)=x-B f(x,t).
η ≥ sup_t ||B f(c,t)||∞,
κ ≥ sup_(x∈X,t∈[0,1]) ||I-B D_x f(x,t)||∞.
```

若外向舍入区间运算证明

```
κ<1,   η+κr<r,
```

且 X 没有分母极点、满足 §4 假根排除条件，则对每个 t，T_t 是 X 到其内部的严格收缩。Banach 定理给出唯一精确根 x(t)；`||I-BDf||<1` 同时保证 Df 可逆，根随 t 连续（局部解析）。因此这一整段路径有唯一正则提升。

这是一种保守但清楚的参数 Krawczyk/收缩证书。变量尺度差异大时可用固定对角缩放；需把缩放后的范数和盒明确写入证书，而非修改公式后不记账。

如果固定中心盒太宽，先二分参数段、用旧轨迹插值并 Newton 重新选中心；仍不通过时提升精度或改用移动中心管道。不通过只能记 inconclusive，不能当作穿奇异，更不能以采样余量替代区间余量。

参数 Krawczyk 路径认证有直接参考：[Certified homotopy tracking using the Krawczyk method](https://arxiv.org/abs/2402.07053)。端点根认证与整段认证须区分：[Certifying zeros of polynomial systems using interval arithmetic](https://arxiv.org/abs/2011.05000)。这里给出的是自足的充分条件，不要求照搬某个实现。

## 6. 相邻盒必须证明是同一个根：仅“有交集”不够

令已认证段的盒为 X、右端为 t=1。以区间算术计算

```
E = c-B f(c,1) + (I-B Df(X,1)) (X-c).
```

精确右端根属于 E。若严格证明 `E ⊂ interior(X_next)`，则它也是下一段盒中的根；由下一段唯一性，两段提升接起来。

若包含关系不成立，细分或另认证一个较小的节点根盒 E_node，并证明它包含的同一个根位于两段盒中。**两个盒相交并不能证明两盒里的唯一根相同。**

基点先认证六个两两不交的根盒。每条路径起始根盒应包含于其第一段盒；最后一段的端点根包络应严格包含于预期基像的根盒。这样根编号与置换由包含关系决定，而非最近邻浮点距离。

同一个最终根可以按不同精度给出多个盒，但这些盒的根身份也必须用包含/唯一性连接。任意阈值聚类不进入证明。
