# 固定 SR5 的代数不可解性：16 次消元、算术 S16 与几何正规子群

## 1. 本轮结论与证明路线

对配置 `model/configs/rokae_sr5.yaml` 的**固定**精确有理机械参数，位置与姿态作为变量，其 IK 的几何单值化群 G 满足

```
A16 <= G <= S16.
```

因此该固定臂的一般 IK 不能用根式表示。这里不声称每个特殊目标都没有简单解，也尚未区分 G=A16 或 S16。

这是本轮推导出的另一条严格代数证明路线，不需要等待 a、d、h 长回路的区间提升。旧 Gate C 的路径认证依然未完成，不能把本结果写成那些回路已经认证。以下证明和脚本均待其他研究者独立复核。

主要环节：

1. 从 SR5 精确 FK 推导通用次数至多 16 的单变量消元，并给出有理逆恢复；
2. 一个合法有理位姿的多项式，模 41 不可约、模 43 的分解次数为 3+13，推出该特化的算术群为 S16；
3. 合法同次数可分特化的群嵌入通用算术群，故通用算术群为 S16；
4. 几何群正规于算术群，且 FK 源空间几何不可约，使几何作用传递；S16 的正规子群分类迫使几何群至少为 A16。

**第 4 步不能省略。** 单个位姿上有 S16 算术群并不自动否定复数常数域上的根式解。这里利用具体 FK 源的几何不可约性，把算术常数扩张可能造成的假证据排除。

## 2. 精确机械几何

令

```
phi=q1, u=q2, theta=q2-q3,
delta=17/125, ell=207/2000, h0=41/125.
```

设目标旋转 R、位置 p，n=R e_z，减去最后一段沿末轴的位移：P=p-ell*n。

前三关节及第四关节固定 link 后、第四关节旋转前的原点 C 和轴方向 m 为

```
C=(r cos(phi), r sin(phi), h0+z_C),
r=(8 sin(theta)+8 sin(u)-cos(theta)+cos(u))/20,
z_C=(sin(theta)-sin(u)+8 cos(theta)+8 cos(u))/20,
m=(sin(theta)cos(phi), sin(theta)sin(phi), cos(theta)).
```

脚本直接相乘库配置的精确矩阵，符号验证这些公式。

定义 e_rho=(cos(phi),sin(phi),0)，e_phi=(-sin(phi),cos(phi),0)，
l_theta=cos(theta)*e_rho-sin(theta)*e_z。令 w=P-C。腕部几何给出

```
w·m=0,  w·w=delta²,  w·n=0.
```

这是因为 w 是沿第四关节旋转后局部 y 轴的 delta 偏置；第五与第六轴正交，而 n 是第六轴。由这些约束和单位向量关系可反向恢复所有腕部转角，见 §5。

## 3. 降到两个线性方程和一个二次约束

记

```
rho=P·e_rho,  tau=P·e_phi,  Z=P_z-h0,
nu=n·e_rho,   eta=n·e_phi,  m_z=n_z.
```

由 w·m=0，可写

```
w=tau*e_phi+k*l_theta,
k²=delta²-tau²=K.
```

除去 theta 对 C 的贡献，剩余 u 向量的两个坐标为

```
r_u=rho-k cos(theta)-[(2/5)sin(theta)-(1/20)cos(theta)],
z_u=Z+k sin(theta)-[(1/20)sin(theta)+(2/5)cos(theta)].
```

它们必须满足 `r_u²+z_u²=13/80`。展开后，结合 w·n=0，得到关于 s=sin(theta)、c=cos(theta) 的线性系统：

```
A*s+B*c+C=0,
D*s+E*c+F=0,

b=1/10-2k,
A=-(4/5)rho-b*Z,
B=-(4/5)Z+b*rho,
C=rho²+Z²+k²-k/10,
D=-k*m_z, E=k*nu, F=tau*eta.
```

设 Delta=A*E-B*D，则在 Delta≠0 的开集上

```
s=(B*F-E*C)/Delta,
c=(D*C-A*F)/Delta.
```

代入 s²+c²=1，得到

```
V=(B*F-E*C)²+(D*C-A*F)²-Delta²=0.
```

## 4. 为什么一般次数确实至多 16

定义与 phi 无关的目标常数

```
C0=delta²-(P_x²+P_y²),
J=P_x*n_x+P_y*n_y.
```

旋转坐标恒等式给出 `K=rho²+C0`、`F=J-rho*nu`。先将 V 对 `k²-(rho²+C0)` 取余，得到

```
V ≡ f0(rho,nu)+k*f1(rho,nu).
```

精确符号计算验证：f0 关于 `(rho,nu)` 的总次数≤4，f1≤3，故

```
f0²-(rho²+C0)*f1²
```

总次数≤8。这里 Z、m_z、C0、J 都是系数参数。

令 t=tan(phi/2)，d=1+t²，则 rho、nu 都是分母 d、分子次数≤2 的有理式。乘 d^8 得到 t 次数≤16 的多项式。

当 f1≠0 时，`k=-f0/f1`，再解上述线性系统即可唯一恢复 theta。下面的有理特化给出次数**恰为 16**的可分多项式，且所有恢复分母与它互素，因此这些例外不是整族上的恒等障碍。通用合法开集上，t 和其余所有关节代数坐标有理对应，次数恰为 16。

JSON 保存了完整 f0、f1 和特化多项式系数。这里的 d^8 清除分母和总次数界，是一般几何推导，不是从一个数值多项式猜测次数。

## 5. 有理恢复与排除伪根

先由 t 恢复 phi，随后恢复 k、sin(theta)、cos(theta)。肩部逆线性变换为

```
cos(u)=[(1/20)r_u+(2/5)z_u]/(13/80),
sin(u)=[(2/5)r_u-(1/20)z_u]/(13/80).
```

由 `(u,theta)` 恢复 q3=u-theta 的正余弦，不必引入反三角函数。

令 Q4 为第四关节旋转前的精确旋转矩阵。由于 w⊥m、w²=delta²，

```
sin(q4)=-(Q4ᵀw)_x/delta,
cos(q4)= (Q4ᵀw)_y/delta.
```

令 Q5=Q4*Rz(q4)*Rx(pi/2)。由于 n⊥w、n²=1，

```
sin(q5)=-(Q5ᵀn)_x,
cos(q5)= (Q5ᵀn)_y.
```

Q6=Q5*Rz(q5)*Rx(-pi/2) 的末轴就是 n，所以 Q6ᵀR 固定 e_z，属于平面 SO(2)。其 (0,0)、(1,0) 条目恢复 cos(q6)、sin(q6)。

这些构造同时证明所有关节 `cos²+sin²=1`，并重建原始完整 FK；反方向由机械链推导已给出。变量分母仅来自 d、f1、Delta；其余几何长度为固定非零有理数。因而不是只验证一个必要消元条件。

在下述特化，脚本对这些例外的分子、分母逐项计算 gcd，均与 P16 互素。还在精确数域 `Q[t]/(P16)` 中，**同时对全部 16 个代数根**执行上述恢复，用配置的原始六个 link 相乘，精确得到目标 4×4 FK，六个关节单位圆关系全部成立。另以 `F41[t]/(P16 mod 41)` 独立重复完整 FK 重建。两者都无浮点容差。

这不同于旧 skew(R) 平方系统的假根排除：这里直接恢复并核验完整旋转矩阵。

## 6. 一个合法有理位姿与两个素数

选

```
R* = [[ 2/3,  1/3, 2/3],
      [-2/3,  2/3, 1/3],
      [-1/3, -2/3, 2/3]],
p* = (369/1000, 469/2000, 469/1000).
```

严格有 `R*ᵀR*=I, det R*=1`。相应 `P=(3/10,1/5,2/5)`、`Z=9/125`。机械参数仍是固定 SR5，改变的是目标位姿。

所得 primitive 整系数 P16 的系数完整保存在证书。其首项系数为 318264612923810633804361，常数项为 145450243664582637644361。它平方自由，恢复分母均不消失。

将模素数多项式正规化为首一，得到：

* mod 41：不可约 16 次；
* mod 43：不可约 3 次与 13 次的乘积。

模 43 的首一因子系数（从高次到常数）为

```
[1,20,0,38]
[1,8,35,39,20,37,5,23,10,23,40,26,25,33].
```

每个模因子的不可约性另用 Frobenius/Rabin 判据检查：`x^(p^d)=x mod f`，且对 d 的每个素因子 q，有 `gcd(f,x^(p^(d/q))-x)=1`。同时检查因子乘积、次数保持与平方自由。

## 7. 算术群是 S16

记特化多项式的算术 Galois 群为 H。

* mod 41 不可约，故 P16 在 Q 上不可约，H 传递；Dedekind 循环类型给出一个 16 循环。
* mod 43 的 3+13 类型，取三次幂得到一个纯 13 循环。
* 传递 16 点作用若有非平凡块系，块大小与块数均≤8。13 循环在块集上只能恒等，又不可能在一个大小≤8 的块里有长度 13 的轨道，矛盾。因此 H 本原。
* Jordan 定理：本原群含素数 p 循环、且 p≤n-3 时，包含 A_n。这里 p=13、n=16，故 A16≤H。
* 16 循环为奇置换，故 H=S16。

Jordan 判据可核对 [Gareth A. Jones, Primitive permutation groups containing a cycle](https://arxiv.org/abs/1209.5169)。本处不用将数值回路的置换当成严格输入。

## 8. 从算术特化到固定臂的几何群

令 Y=SO(3)×A³，均在 Q 上定义，X=(SO(2))⁶ 是关节正余弦空间。X、Y 都几何不可约；X 的有理函数域也是六个半角参数的纯超越域。

第 2–5 节给出通用有理重建，说明 X→Y 的次数为 16，t 是通用 IK 扩张的本原元。设通用算术分裂群为 G_ar≤S16。

在 Cayley 目标坐标图中，系数为 Q 上的有理函数；上述 R* 的迹为 2，因此处在合法 Cayley 图中。将 P16 的首项系数和判别式倒置，可得包含该有理点的开集，其根覆盖有限 étale。该有理纤维的算术群嵌入 G_ar（选择一个根标记后，来自分解群/étale 纤维作用）。因为纤维群为 S16，得到 `G_ar=S16`。

令 G_geom 为将目标系数的常数域扩至代数闭包后的分裂群。它正规于 G_ar：在分裂域中取代数常数域 C，`G_geom=Gal(E/C(Y))`，商是常数扩张的 Galois 群。X 几何不可约保证 G_geom 对十六个根传递。这也可用 étale 基本群的算术–几何正合列表述，见 [Cadoret, Galois Categories, §7](https://www.math.u-bordeaux.fr/~acadoret/fg.pdf)。

n≥5 时 S_n 的正规子群只有 1、A_n、S_n。平凡群不能在十六根上传递，所以

```
A16 <= G_geom <= S16.
```

特征零下扩到 C 不改变这个有限几何群；对应复覆盖的几何单值化作用。因此固定 SR5 的 IK 扩张不可解，不能用根式给出一般解。

如果删去几何不可约性，推理就不成立。例如一个与位姿参数完全无关的不可约 S_n 算术多项式，在 C 上只是 n 条常值分支；其几何群平凡。这解释了为什么本证明没有重犯“算术或另一参数族证据直接迁移”的旧错误。
