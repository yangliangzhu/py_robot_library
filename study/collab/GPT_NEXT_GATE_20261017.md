## 1. 新定理：当前 3R 模型不是 cuspidal

不仅 exp48 那条路线失败；从原 FK 可以证明，这台具体 3R 模型的任何两个不同正则位置逆解（按关节角模 2π）都不能由无奇异路径连接。这个结论不涉及所有正交 3R，也不否定文献中其他 cuspidal 机械臂。

### 证明

沿用已独立验证的原 FK，u=q2、v=q3：

```
A = 2 sin u + (3/2) sin v cos u
p_local = (1+A, (3/2)cos v-1, z)
z = (3/2) sin v sin u - 2 cos u
R = px²+py², S=R+z², D=S-33/4, w=cos v.
```

q1 绕世界 z 轴旋转 p_local 的水平分量。原位置 Jacobian 的精确行列式为

```
det J_position = (3/2) sin v * g,
g = A + (3/2) cos v.
```

这也可由上一轮 `det D_(u,v)(R,z) = -3 sin v*g` 与柱坐标变换得到；最后公式作为三角恒等式在 ρ=0 也成立。

在任何非奇异连续路径上，两个连续实函数 sin v、g 均不为零，因此二元标签

```
(sign(sin v), sign(g))
```

各自保持不变。注意这里只证明标签是路径不变量，尚未假设标签等于 aspect。

固定一个目标位置，由原 FK 有

```
A = (D+3w)/2,
P(w)=18w²+6Dw+D²+4z²-25=0,
P'(w)=36w+6D=12g.
```

对于两个不同的实二次根，P' 的符号相反。故指定 sign(g) 就唯一确定可用的 w；若是重根则 g=0，不是正则解。

再指定 sign(sin v)，由 w=cos v 唯一确定 v mod 2π（正则条件排除了 sin v=0）。令 b=(3/2)sin v，有

```
[A] = [2  b] [sin u]
[z]   [b -2] [cos u],

sin u = (2A+bz)/(4+b²),
cos u = (bA-2z)/(4+b²).
```

分母严格正，所以 u mod 2π 也唯一。正则解必有 ρ>0，因为水平位置为零时 q1 的位置 Jacobian 列为零。于是目标方位角唯一确定 q1 mod 2π。

因此，**同一个正则位置纤维中，每个符号标签至多含一个构型**。而无奇异路径必须保持标签，故不可能把两个不同逆解连接起来。证毕。

## 2. T5 的 SVD 公式需要修正，且当前仍非完整机器认证

文件：`exp63_segment_certificate._svd_sigma_min_lower`。

设 A 近似 U diag(s) Vᵀ，已验证误差满足

```
||UᵀU-I||₂ ≤ δU < 1,
||VᵀV-I||₂ ≤ δV < 1,
||U diag(s) Vᵀ-A||₂ ≤ δR.
```

正确的下界是

```
σ_min(A) ≥ s_min * sqrt((1-δU)(1-δV)) - δR.
```

当前代码用 `1-(δU+δV)/2` 替换平方根。这是该平方根的**上界**（算术–几何平均不等式），不是下界，不能这样替换。免平方根的较保守选项是 `(1-δU)(1-δV)`，或 `max(0,1-δU-δV)`，最后整体下界再截到 0。

### 精确反例及实际函数复现

取一维矩阵 `U=A=√(9/10)`，s=V=1。则 δU=1/10、δV=δR=0，真实奇异值为 √0.9≈0.9486833，错误公式给出 0.95。当前函数的浮点膨胀不能修复这一数学错误：

```bash
python3 - <<'PY'
import numpy as np
from study.exp63_segment_certificate import _svd_sigma_min_lower
a = np.array([[np.sqrt(.9)]])
bound = _svd_sigma_min_lower(a, a, np.array([1.]), np.array([[1.]]))
print('true:', a[0,0], 'reported lower:', bound)
PY
```

本轮实跑：`true: 0.9486832980505138 reported lower: 0.9499999999999986`。

该探针把可验证的近似分解送入底层函数，并非声称 NumPy 正常 SVD 会产生如此不正交的 U。对于正常 SVD，误差通常极小，错误的二阶项可能远小于余量；所以本结果否定的是当前“严格下界”的一般证明，不是自动否定 SR5 那条路径确实无奇异。
