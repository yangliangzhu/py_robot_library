# 协作区：给"提问者 + kimi + 我"共用的工作台

目的：让三方异步共读、共算、互相复核。提问者是问题的发起者与最终判官；kimi 与我是两个 AI，
各自独立读文献、跑实验、写批注。

## 文件约定

| 文件 | 谁写 | 内容 |
|---|---|---|
| `README.md`（本文件） | 任何一方 | 协作协议、进度表、待认领问题 |
| `dayNN-dsh.md` | 我 | 当天讲义：概念 → 我们的数据 → 可复现命令 → 练习 |
| `dayNN-kimi.md` | kimi（或提问者转贴） | kimi 的批注、复核、反驳、补充文献 |
| `dayNN-result.md` | 任何一方 | 当天实验的实际输出（命令 + 数字） |
| `QUESTIONS.md` | 任何一方 | 待解问题清单，可认领、可标记状态 |

## 协议（三条，都是本课题已经吃过教训的）

1. **每个论断必须带产生它的命令与数字**；没有命令的论断标为"猜想"，不许写进结论。
2. **分歧用测量裁决**，不靠说服。若一时测不了，写明"未决"与"为什么测不了"。
3. **可以互相攻击**：kimi 优先做三件事 —— 复现我的实验、替我找反例、补我漏掉的文献。
   我被要求做同样的事。

## 术语对照（先钉死，避免各说各话）

| 本课题用词 | 机器人学文献 | 代数/几何（提问者熟悉的语言） |
|---|---|---|
| 关节空间 `Q`、奇异集 `Σ` | joint space, singularity surfaces | 底空间上的分支轨迹；`Σ` = 判别式 locus |
| chamber / **aspect** | aspect（Borrel & Liégeois 1986） | 覆盖空间 `Q\Σ` 的连通分支 |
| 一个解 = **posture** | posture（Angeles、Wenger） | 方程 `f(q)=T` 的一个根 |
| 不穿奇异换解 = **cuspidality** | cuspidal robot | **实**单值化非平凡：实根被实回路置换 |
| 覆盖层数 `d_C ≈ 6` | 一个 aspect 里的唯一性域个数 | 该连通分支的**次数**（fiber 大小） |
| **monodromy 群** | （机器人学罕见） | 伽罗瓦群（Harris 1979：单值化算伽罗瓦群） |
| `sign det J` | 同 aspect 的必要条件 | 判别式符号：分支的"侧" |
