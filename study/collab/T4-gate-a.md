# T4 Gate A — 固定 SR5 位姿空间复回路：一条可靠完整置换

执行者：`pose-loop-gate-a`（T4 分工）。范围：**只做 Gate A**，不做 Gate B（非可解子群判定）、
不做 Gate C（路径认证）。本文是「一次可靠完整置换」的交付记录。

## 1. 结论（先读这个）

在**固定 SR5** 臂（`links[4][1,3] = 0.136 m`，机械参数全程不动）上，取基位姿 `T0`（`seed=0`，
`p0=[0.0821, 0.1012, 0.7846] m`），沿合法复位姿坐标 `p(u)=p0+u·d`、`d=[0,0,-1]`（**姿态固定**，
GPT §C1 的「平移分量非零、姿态固定」版）找到**简单源 fold** `u* = +0.283606`（§C2 增广系统
`[err6; det J]=0`，残差 `2.2e-10`），绕其做一条闭复环（半径 `5e-3`，上半平面弧线避开复根的
birth fold），跟踪**全部 16 根**（10 实 + 6 复），读得

```
完整置换 σ = (1 6)   ——  像列表 [0, 6, 2, 3, 4, 5, 1, 7, 8, 9, 10, 11, 12, 13, 14, 15]
```

即 **一条对换（transposition）**，其余 14 根不动。四条闭环（σ、逆环、空环、步长加密复跑）
全部 16 根逐根匹配、单射，自检 8/8 通过，`exit 0`。

**可靠性声明（不越界）**：这是一次**数值**单值化测量。四组一致性（逆环 = σ⁻¹、空环 = 恒等、
加密复跑 = σ）给出强数值支持「该置换是回路的真实效应、不是跟踪器伪影」，但它**不是**机器认证
（那是 Gate C），**不**构成任何可解性/不可解性判定（那是 Gate B）。单条对换只生成 C₂（可解），
所以**本交付物本身对「固定 SR5 不可根式解」这个总目标不提供任何结论**。

## 2. 实现内容

`study/exp64_pose_loop_gate_a.py`（编号已登记进 `QUESTIONS.md`）。模块做了：

1. **机械参数指纹**：18 个平移分量打印确认 `links[4][1,3]=0.136` 全程未动。
2. **16 根全纤维**（`exp38` 的确定性构造，`seed=0`）：10 个实根来自 torus 去重的
   物理可容许 census（400 种子），6 个复根来自 s-族三个 death fold 的合流对沿参数延拓回 `s=1`。
   逐根残差 `≤1.1e-5`（实）`≤1.6e-14`（复）。
3. **目标路径公式**：`p(u)=p0+u·d`，`d=[0,0,-1]` 单位化，`u` 复数，姿态块固定。
4. **fold 定位（C2）**：沿实轴 `u` 扫 10 个实根，最近对（根 1、6）间隙 `4.4e-2` 处停下，
   2π 对齐后取中点做增广系统 `[err6; det J]=0`（未知 `(q,u)`，7 复未知量）精化 →
   `u*=0.283606`，`det J ≈ -3e-10`。
5. **闭复环（C1/C3）**：`u: 0 → (上半平面弧, Im=0.05) → u*−5e-3 → 绕 u* 一圈 → 原路返回 0`。
   上半平面弧是为了**避开复根（10–15）在实轴上的 birth fold**（实测它们沿实轴在
   `u≈0.018`、`u≈0.128` 处合流成实，牛顿无法穿过去）。
6. **恒等记账**：线性预测 + 跳盆拒收（0.5 rad）+ 终点单射匹配；**未匹配根 = 失败态**，绝不默认
   成固定点。per-step 合并护栏按 exp58/59 的纪律放在**扫描**里（`min_pair_gap`），回路本身靠
   跳盆拒收 + 终点单射 + 四组一致性。
7. **自检（Gate A §3 第一清单）**：σ、逆环、空环、加密复跑；`reverse==σ⁻¹`、`empty==id`、
   `refined==σ`、`σ∘σ⁻¹==id` 全过，否则 `exit 1`。

## 4. 实现了 C1–C3 的哪部分

- **C1（合法复位姿坐标）**：实现了「`tau(u)=tau0+u·d`、`d` 平移分量非零、姿态固定」的最小版本
  （方向 `-z`）。未用 Cayley/Rodrigues 图的显式 `vee((R-I)(R+I)^{-1})` 坐标（姿态固定时不需要），
  也未用关节 Laurent 变量 `z=exp(iq)`；用的是复角局部坐标 + 复安全残差
  `err6_complex`（位置 + 反对称旋转），复数值保留实虚部。
- **C2（求切片简单分支点）**：实现了增广系统 `[err6; det J]=0` 在 `(q,u)` 上的牛顿精化（7 复未知
  量）；`u*` 收敛到 `det J≈0`、`u*` 实。**未做** §C2 的显式非退化检查
  `lᵀG_λ≠0`、`lᵀD_z²G[v,v]≠0`（未构造左零向量 `l`）；「简单 fold」由「gap 平方根消失 + 环读出
  单一对换」间接佐证，不是严格横截验证。
- **C3（最小成果与失败条件）**：实现了共同基点、16 根全纤维、完整置换、逆向/空环/加密复跑、
  未匹配 = 失败态、复数据实虚部保留。**未做**「上界适用」的严格证明（Gate C）。

## 5. 未实现 / 边界

- **Gate B（非可解子群）**：未做。单条对换 (1,6) 只生成阶 2 的循环群（可解），
  **不得**据此说任何不可解结论。
- **Gate C（认证）**：未做。这是数值测量（`machine_verified=False` 的语义），不是整段路径认证。
- **C1 的 Cayley 图 / 平方系统**：未实现 GPT §C1 的 Cayley 图 `R(w)` 与关节 Laurent 化 `G(z,λ)`；
  用复角局部坐标替代（§C1 明确允许「暂用复角度作数值局部坐标」）。
- **C2 的非退化检查**：未实现左零向量 `l` 的两个非零条件。
- **更多生成元**：只交付**一条**可靠置换。按「先可靠、再扩大搜索」的节奏，未为凑更多生成元而
  扩大搜索。

## 6. 未决（诚实记录，不默认成固定点）

1. **环是否只包住一个分支点**：测得的是一条约 (1,6) 对换，说明「该环内的分支点（或共享临界值的
   一组分支点）净效应是一条对换」。我没有显式普查 `u*±5e-3` 邻域内是否还有别的分支点被同时包住；
   共享临界值的教训（§C2 警告）在**这条**环上表现为「净置换仍是一条对换」，但**未**逐一分离验证。
2. **复根 10–15 的 birth fold 精确位置**：实测沿实轴在 `u≈0.018`、`u≈0.128` 处合流（牛顿在实轴上
   无法穿过），环用 `Im=0.05` 弧线避开，绕环后 10→10、…、15→15 全部自返；但这两个 birth fold 的
   **精化位置与确证**未做（不是本 Gate 的目标）。
3. **fold 的非退化**：未做 §C2 的 `lᵀG_λ`、`lᵀD²G[v,v]` 检查，「简单 fold」是间接证据。
4. **复根实部很大**（如根 14 实部 ~ −35..41，是参数延拓到 `s=1` 时的 2π 未折代表），torus 匹配
   按实 2π 折回，判定为同一根；这些代表未做物理限位折叠，不影响置换读数。
