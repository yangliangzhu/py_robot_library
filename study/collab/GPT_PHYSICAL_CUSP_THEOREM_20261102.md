# 一个物理扰动定理与严格的“根式可解且 cuspidal”实例

2026-11-02，GPT 独立推导与实现，实验 `exp74_physical_cusp_unfolding.py`。

## 1. 本轮得到的数学结论

**定理 A（任意小物理扰动产生普通 cusp）。** 保持原 DEFAULT 的其余参数不变，只把第三个 MDH 行 `[2,pi/2,0]` 改成 `[2,pi/2,ε]`。存在 ε₀>0，使每个 `0<|ε|<ε₀` 的臂都在原 `(R,z)=(1/2,sqrt(7)/2)` 退化点附近产生普通 cusp。该族的位置 IK 对所有 ε 仍可化为四次方程。因此 DEFAULT 的非 cuspidal 性在这条物理参数方向上不稳定。

**定理 B（具体有理参数正见证）。** 取 ε=1/10，得到一台根式可解且 cuspidal 的位置任务 3R。其普通 cusp 有精确代数定位；更重要的是，另给出同一目标位置的两个不同正则逆解和一条完整的非奇异连接路径。连接证明由有理不等式、单调性和 Sturm 根计数完成，**不依赖数值网格连通，也不依赖仅凭“有 cusp”推断换解**。

定理 A 的“充分小”没有给出显式 ε₀；不能据此直接代入 1/10。定理 B 是独立的精确验证，填补这一点。DEFAULT 保留不变，仍是非 cuspidal 的解析对照。

## 2. 从真实 MDH 到精确 FK

约定与库相同：每行 `[d,alpha,a]` 对应 `Tx(a) Rx(alpha) Tz(d)`，然后施加该关节的 `Rz(q)`。

```
rows = [(0,0,0), (1,pi/2,1), (2,pi/2,ε)]
tool = (3/2,pi/2,0)
```

令 `u=q2, v=q3`，在 q1=0 的局部坐标中：

```
B = ε + (3/2) sin v
A = 2 sin u + B cos u
z = B sin u - 2 cos u
p_local = (1+A, (3/2)cos v-1, z)
R = p_x²+p_y²
A²+z² = 4+B²
R+z² = 33/4+ε²+3ε sin v+2A-3cos v.
```

exp74 直接相乘精确 MDH 矩阵核验这些恒等式。另与库 FK 做 100 组随机交叉检查，最大误差 6.67e-16；后者只是实现对齐检查。

在 A<0 分支，因 `∂z/∂u=A≠0`，可用 `(z,v)` 作为真实源坐标。约化位置映射为 `(z,v) -> (z,H(z,v,ε))`：

```
H = 33/4+ε²+3ε sin v-z²
    -2 sqrt(4+(ε+(3/2)sin v)²-z²)-3 cos v.
```

ρ>0 时，将 q1 换成末端方位角是局部可逆变换，所以整个三维位置映射是该平面映射与一个正则坐标的乘积。

## 3. 小扰动分岔的证明

在 `z0=sqrt(7)/2, v=0, ε=0`，精确计算得到

```
H_v = H_vv = H_vvv = 0,
H_vε = 1,
H_vvvv = 18,
H_zvv = -2 sqrt(7)/3.
```

最后三项揭示原先偶对称的特殊性：物理偏置 ε 引入非零的 εv 项，而未扰动核方向首项为 `(3/4)v⁴`。

设 `b=-sqrt(7)/3`，做实解析加权变换

```
ε=6δ³,   v=δY,   z=z0+δ²Z.
```

将 cusp 方程 `H_v=H_vv=0` 分别除以 δ³、δ²。因 ε=0 时 H 关于 v 偶对称，所得方程可解析延拓到 δ=0，其极限为

```
F1 = 6+2bZY+3Y³ = 0,
F2 = 2bZ+9Y² = 0.
```

有解 `Y=1, Z=27/(2sqrt(7))`。按变量顺序 `(Z,Y)` 的 Jacobian 行列式为 `36b=-12sqrt(7)≠0`。隐函数定理给出 δ 附近的解析解 `Z(δ),Y(δ)`，并且

```
v_c = δ+O(δ²),
z_c = sqrt(7)/2 + (27/(2sqrt(7)))δ²+O(δ³),
H_vvv = 18δ+O(δ²),
H_zv = -(2sqrt(7)/3)δ+O(δ²).
```

所以对充分小的 δ≠0，`H_v=H_vv=0` 而 `H_vvv H_zv≠0`，是普通 cusp 的非退化条件。几何上也能直接看出临界像的半三次 cusp：临界集由 `H_v=0` 解为 z=z(v)，在候选点有 `z'=0, z''=-H_vvv/H_zv`；临界像 γ=(z,H) 满足

```
det(γ'',γ''') = 2 H_vvv²/H_zv ≠ 0.
```

源芽的标准 cusp 形式为 `(X,Y³+XY)`。该形式中，同像的两个正则点 `(-a,-sqrt(a))`、`(-a,+sqrt(a))` 可先到 X=+a、再改变 Y、最后返回 X=-a；沿这三段 `X+3Y²>0`。取足够小 a，路径留在正规形坐标邻域内。由源、目标微分同胚和正则方位角坐标，得到非奇异换解。这证明定理 A 的 cuspidality 后果。

术语及标准正规形可核对 [Kabata, Recognition of plane-to-plane map-germs, Table 1](https://arxiv.org/html/1503.08544)。本节关键的物理可实现性和分岔系数来自上述 FK 推导，不是从文献模型猜测参数对应。

## 4. ε=1/10 的精确普通 cusp

设 `t=tan(v/2), s=2t/(1+t²), c=(1-t²)/(1+t²)`。由 `H_v=0` 定义

```
B=1/10+(3/2)s,
A=-B*c/((1/10)c+s),
z²=4+B²-A²,
R=(1+A)²+((3/2)c-1)².
```

代入 `H_vv=0` 后，分子由下列六次多项式控制：

```
P(t)=497t⁶+180t⁵-3891t⁴+47640t³+5091t²+180t-97.
```

Sturm 方法精确证明区间

```
[92228741610/10¹², 92228741612/10¹²]
```

恰有一个实根。以此根定义 t_c，并取 z>0。Fraction 有理区间计算证明 `A<0, z²>0, R>0, H_vvv≠0, H_zv/z≠0`，所有分母不为零。显示值为

```
t_c≈0.092228741611,  z_c≈1.557990358108,
R_c≈0.320658742710, A_c≈-1.308742094856,
H_vvv≈4.653662078737, H_zv/z≈-0.492551119388.
```

还独立在 IK 四次式上检查：前三个导数阶数 0、1、2 在模 P 的商环中严格为零，第三阶导数区间不含零。因此其重根**恰好三重**，与旧模型的四重退化不同。这里没有把消元重根独自当成 cusp 判据；源坐标和非退化导数已另行检查。

## 5. 不经正规形的显式非奇异换解路径

取目标位置

```
p*=(sqrt(399/1250), 0, 39/25).
```

其 IK 四次式（清除常数分母）为

```
Q(t)=25807364t⁴+3050250t³-2184647t²+237750t-7636.
```

令 t_L、t_R 分别为下列区间中唯一的实根，唯一性由 Sturm 精确保证：

```
t_L ∈ [0.07336875, 0.07336876],
t_R ∈ [0.11720485, 0.11720487].
```

在 `(z,t)` 源坐标中选择三段折线

```
(39/25,t_L) -> (77/50,t_L)
             -> (77/50,t_R) -> (39/25,t_R).
```

每点用 `A=-sqrt(4+B²-z²)`，并恢复真实关节：

```
sin u=(2A+Bz)/(4+B²),
cos u=(BA-2z)/(4+B²),
v=2 atan t,
q1=-arg(1+A+i((3/2)c-1)).
```

根号与分母在整个矩形内严格合法。`(3/2)c-1>0` 保证局部横向向量不为零，arg 可以连续选取。因此该折线对应连续的真实关节路径，其末端位置始终为 `(sqrt(H),0,z)`；**只有两个端点要求末端相同，运动中末端可以移动**。

两端的四次方程和恢复公式精确保证位置为 p*，且 t_L≠t_R 保证关节解不同。显示用的近似关节值在 JSON 中；证明使用代数根本身，不以显示小数作为精确端点。

非奇异性的关键为

```
H_v=3[(εc+s)-Bc/sqrt(4+B²-z²)].
```

整个矩形上 `εc+s>0`、`Bc>0`、根号内正，所以 `H_v>0` 等价于

```
F(z,t)=(4+B²-z²)(εc+s)²-(Bc)² > 0.
```

* 在两个上端点的有理根隔离区间上，有理区间算术直接证明 F>0。
* 两条竖段固定 t，正 z 减小时 F 增大，故全段 F>0。
* 横段 z=77/50：F 的分子多项式在覆盖整个 `[t_L,t_R]` 的有理区间内 Sturm 根计数为 0，且中点为正，故全段 F>0。

再结合 A≠0、ρ>0，整个位置 Jacobian 不为零。这就是具体臂的 cuspidality 直接证明，不需要通过网格认定 aspect。

**负对照**：若不绕到 z=77/50，而直接沿上边 z=39/25 连接 t_L 与 t_R，F 的分子在相同区间内恰有两个零点。该捷径确实穿过奇异集；测试会识别这一点。

## 6. 四次 IK 与根式恢复

对任意固定 ε，令目标高度为 z、水平距离平方为 R，置

```
D=R+z²-33/4-ε²,
s=2t/(1+t²), c=(1-t²)/(1+t²).
```

IK 必须且在上述合法实分支上足以满足

```
(D-3εs+3c)²+4z²-16-4(ε+(3/2)s)²=0.
```

乘 `(1+t²)²` 得到次数不超过四的多项式；脚本符号核对一般次数为四。恢复 `A=(D-3εs+3c)/2`，随后用 §5 的 sin u、cos u 公式。对一般目标 `(x,y,z)`，q1 的正余弦由把局部 `(1+A,(3/2)c-1)` 旋转到 `(x,y)` 的二维旋转公式得到。

因此关节的代数坐标（sin、cos，或半角参数）可由根式求出。角度值本身还需 atan2；这里沿用项目“根式可解”的代数 IK 含义，并不宣称反三角函数也是根式。半角无穷点和 R=0 等特殊图另行处理，不影响一般代数可解性及本实例。
