## 1. 先固定数学对象

实侧记正运动学为 `F_a: Q → SE(3)`，`a` 为机械参数。必须分别指定 Q 是六维环面还是有物理关节限位的盒；两者的连通性可能不同。

复代数侧采用 `z_j = exp(i q_j) ∈ C*`，而不把角度 q 本身当作代数未知量：

```
cos(q_j) = (z_j + z_j^(-1))/2
sin(q_j) = (z_j - z_j^(-1))/(2i)
X = (C*)^6
Y = SO(3,C) × C^3
F_a: X → Y
```

于是 FK 是 Laurent 多项式映射。根式可解性应指 z（或半角变量）的代数函数可解性；从 z 恢复角度另需取对数/选择实角分支。

固定 a 后，若 F_a dominant 且 generically finite，则在适当非空 Zariski 开集 U 上可限制成有限 étale 覆盖，次数记 d。这里需要排除临界值及非有限行为；不能仅由 `det J ≠ 0` 就断言全局覆盖。一般有限性背景见 [Stacks: generically finite morphisms](https://stacks.math.columbia.edu/tag/02NV)。

我们真正想判断的是 `C(X)/C(Y)` 的正规闭包的群，等价于该覆盖的几何单值化群。目标是固定 SR5 的 a，而非默认 a 也在底域中变化。

配置中的十进制长度可作为精确有理数模型的候选定义；必须明确这是设计模型，不能默认为实物参数精确值，也不能自动把浮点三角常数识别成精确代数数。

## 2. 当前机械参数回路不能直接回答固定 SR5 的问题

代码证据：`exp37_complex_loop.links_at` 修改 `links[4][1,3] = offset*s`；目标 T 保持不变。`exp38` 的纤维虽然以 s=1 为基点，回路仍在机械参数空间里运动。

即使已严格认证这些置换，它们首先属于固定 T、变化 s 的覆盖。它们可以作为适当总参数覆盖的子群证据，但不能直接当作固定 s=1、变化 T 的群证据。

### 一个保持次数与简单根的反例

考虑方程

```
P(x; a,t) = x^5 - x - (a-1)t = 0.
```

固定 t=1，让 a 变化。映射 `a=x^5-x+1` 的四个有限临界点满足 `5x^4=1`，均为简单临界点，临界值 `1-4x/5` 互异。各局部单值化为对换；去掉有限临界值及其原像后，源空间仍连通，因此单值化作用传递。复平面去掉这四点的基本群由四个小回路生成，所以群由对换生成且传递，等于 S5。

然而固定 a=1，方程是 `x(x^4-1)=0`，五个根 `0, ±1, ±i` 与 t 无关，均为简单根，位姿参数 t 上的群是平凡群。机械参数族的不可解性没有传到这一固定参数切片，甚至无需降低多项式次数或让该切片的根重合。

这不是 SR5 可解的证据；它严格否定的是不附条件的推理规则。

### 可用的直接证据形式

锁定 a=a_SR5，在 U 内取共同基点 T0 的闭回路，认证整条路径提升与终点置换。它们生成的 H 是固定机械臂单值化群 G 的子群。若 H 不可解，则 G 不可解。无需求出完整 G，也不必先证明 G=S16。

若真实生成元确实是单独的对换，连通五个根的四条树边已足以生成 S5。若一个回路同时交换多对根，不能拆成互相独立的对换生成元；必须使用完整置换做群计算。

现有回路也可能通过更深的几何论证转移到固定位姿族，但目前未建立这种转移。不能把“参数一般”当作“特定 s=1 已证明一般”。

## 3. 已复现的跟踪器控制流缺陷

位置：`exp38_monodromy_group.track_path`，同型结构见 `exp37_complex_loop.track_circle`。

代码在当前目标步过大时缩小 span；接受中间点后，立即进入下一个外层目标，未保证走完当前段。若最后一段也缩小，就会在未到达终点时返回成功。

2026-10-16 可控探针结果：令真实根路径 `q(s)=s`，校正器返回精确根、残差恒为零，目标参数 `[0,1]`，`max_step=0.1`。

```
尝试参数：1, 0.5, 0.25, 0.125, 0.0625
返回 q = 0.0625
返回 ok = True
```

复现方法见配套任务 T1 的内嵌脚本。此探针证明函数的成功语义有缺陷；尚未证明历史哪条边因此错误。某些调用者另外检查目标终点残差，能拦住部分错误，但不能修复函数本身的契约。

另外，`exp37` 的远离 fold 负对照直接复用了原 fold 附近的根，没有先建立新圆基点上的纤维。修复时需在新基点取根并与同一新基点的终点比较。

## 4. 3R：相切证明了什么，尚未证明什么

沿用 `exp54` 的系数，令 R=ρ²、Z=z²、S=R+Z：

```
A0 = 16S² - 360R - 296Z + 1769
A1 = 16S² - 168R - 104Z + 185
A2 = 16S² - 264R - 200Z + 401
C  = 16S² - 264R - 136Z + 289
P(t) = A0*t^4 + 2*A2*t² + A1
A2² - A0*A1 = -576*C
```

以下等式已用 SymPy 精确有理运算核对。

在 `(R,Z)=(1/2,7/4)`，`(A0,A1,A2)=(1152,0,0)`，所以 P=1152t⁴，t=0 为四重根。在 `(25/2,7/4)`，系数为 `(0,1152,0)`，换坐标 u=1/t 后，反向四次式在 u=0 为四重根。

令 x=R-R0、y=Z-Z0。在第一点：

```
A1 = -96x - 32y + 16(x+y)²
C  = -192x - 64y + 16(x+y)²
C - 2*A1 = -16(x+y)².
```

两分量梯度非零，公切线 y=-3x；沿切线右边为 -64x²，二阶接触非零。在第二点：

```
A0 = 96x + 160y + 16(x+y)²
C  = 192x + 320y + 16(x+y)²
C - 2*A0 = -16(x+y)².
```

公切线 y=-3x/5，沿切线右边为 `-64x²/25`，同样二阶接触。两个分量在各点都是光滑分支，且是两个不同的解析分支；它们的约化并集是 ordinary tacnode 型的局部曲线，而非普通半三次 cusp 的单个奇异解析分支。由于 ρ,z 在这些点都非零，`(ρ,z)↔(R,Z)` 局部可逆，不改变此区别。

**严格范围**：这是给定判别式分量的局部曲线分类。尚未证明这些消元分量与原 FK 的临界像在每一处完全等价，也未分类所有源构型；一个投影变量的四重根本身不能直接确定原映射的奇点类型。

因此当前“切向夹角很小 ⇒ 普通 cusp 已证明”的推理不成立。接下来应在原 FK 上逐个重建奇异构型、计算局部正规形；也须明确原作者是否将 cusp 用作更宽泛的非普通奇点术语。此处不重新宣称“该臂完全没有 cusp”，也不否定已有非奇异换解的数值路径。

## 5. 实路径证书的可行升级

`chamber._segment_min_sigma` 与 `_segment_clears` 是有限采样。对一段 `q(t)=q0+t*d, t∈[0,1]`，若有经验证的常数

```
||dJ(q(t))/dt||₂ ≤ L,
```

且采样覆盖半径为 h，那么由奇异值扰动界，整段满足

```
σ_min(J(q(t))) ≥ min_k σ_min(J(q(t_k))) - L*h.
```

右侧严格正（并计入数值误差）即可证明该段无奇异；若要求间隙 δ，则需右侧至少 δ。L 可用区间 Hessian/导数界给出，但有限差分测得的最大值不是严格上界。平移与转动行混用单位时需声明固定缩放；非奇异性不变，数值间隙会变。

- 实侧 aspect 连通性不能自动等同于某个正则目标域上的 monodromy 轨道。见证路径的像可能穿过别的根对应的临界值。要先指定覆盖底空间。
- 由 `f(∂A)⊂Δ` 不能推出“目标落在 Δ 当且仅当当前构型穿过该 aspect 的特征曲面”。必须检查具体原像与 aspect。

## 7. 数值与认证分层

低残差、步长加密一致、正反回路一致是重要数值证据；它们不自动认证整段根身份。可考虑区间方法或认证延拓。

[Hauenstein–Sottile, alphaCertified](https://arxiv.org/abs/1011.1091) 提供平方多项式系统的根认证工具背景；不能把其对超定系统的启发式验证当作精确证明，也不能把端点根认证当作整条路径认证。

本轮优先顺序：修复跟踪契约 → 统一可重放数据 → 固定 SR5 位姿回路 → 认证最小非可解见证。3R 局部分类可以作为独立支线。
