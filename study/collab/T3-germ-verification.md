### 3.3 局部代数：重数 4（而不是 cusp 的 3）

* `R(z₀, y) − R₀` 的 y-Taylor：只有偶次项，二次项 = 0（就是 `B(z₀)=0`），**首个非零项在 4 次**（= `C₀ = ±3/4`）⇒ 局部代数 `ℂ{y}/(y⁴)`，重数 **4**；
* 辐角原理数局部原像（generic 扰动，`|y| = 0.12 / 0.2 / 0.4` 三个半径）：四点全部 **4.0**（与半径无关）；
* 对照：普通 cusp `(x, y³+xy)` 的局部代数是 `ℂ{y}/(y³)`，重数 **3**（脚本用 Groebner 现算）；
* 源侧临界集 = `{y=0}` ∪ `{H_r=0}`（后者是 `y² = r_c(z)`，切线方向 (0,1)，与前者 (1,0) 横截）——**两条**横截光滑曲线，不是 cusp 的一条。

### 3.4 A4 的构造：逐步执行（40 位精度，四点）

我按 A4 的路线显式取：

```
k(z,r) = (r − r_c(z))·sqrt(|G|),   G = (H(z,r) − H(z,r_c(z)))/(r − r_c(z))²,   r = y²
a(z) = k(z,0),   b(z,y²) = (k(z,y²) − a(z))/y²,   σ = sign(b)
源:  X = 2σ a(z),  Y = y·sqrt(|b(z,y²)|)          目标: V = (R − H(z,r_c(z)))/ε₁ − a(z)²
```

* `H_r(z, r_c(z)) = 0` 的 Newton 残差 ≤ **1.3e-44**；
* `G` 在邻域内不消失：`|G| ∈ [0.74946, 0.74965]`（原点值 = `|C₀| = 3/4`）⇒ 可开**解析**平方根（A4 的 `K`）；
* `b` 不变号（σ = +1，四点），`ε₁ = sign(C₀) = ±1`；
* `a'(z₀) ≠ 0`：中心差分 ≈ ∓0.50917539，解析值 `4z₀/9·√|C₀| = 0.50917508`（差来自差分步长）；
* 源变换 `(z,y) → (X,Y)` 可逆：`|det| ≥ 0.9458`（四点）；
* **正规形恒等式 `V = Y⁴ + X Y²` 最大残差 ≤ 4.1e-48**。
  （说明：这条恒等式在构造成立时是代数必然；真正被它检验的是上面那些**假设**——`r_c` 存在且唯一、`G` 非零、`b ≠ 0`、`a' ≠ 0`、变换可逆——以及构造的实现是否正确。A-等价本身由这些假设 + A4 的论证给出，我独立重走了论证：`r ↦ H(z,r) − H(z,r_c(z))` 在 `r_c` 有二阶零点且商非零 ⇒ 可写成 `(r−r_c)²K²`，这正是 A4 的关键一步。）

### 3.5 正规形的推论 vs 真模型（库 FK，每点 120 随机构型）

* **因子化**：`R_fk(u,v) = H(z_fk, (v−v₀)²)`，最大残差 5.6e-16 / 3.6e-15 / 4.4e-16 / 5.3e-15（四点）⇒ 源芽确实就是 `(z,y) ↦ (z, H(z,y²))`；
* **临界集两支**：branch I = `{sin v = 0}`（即 v=v₀，含候选点）、branch II = `{A + (3/2)cos v = 0}`（候选点也在其上，这就是 `B(z₀)=0` 的含义）；
* **branch I 的像**：z **两侧**都有（±3.0e-3），且落在曲线 `R = H(z,0)` 上（≤3.6e-15）——正规形里的 **`V=0` 直线**；
* **branch II 的像**：z **单侧**（四点都是 `[+2.2e-16, +6.8e-4]` 这种一侧区间），且在构造坐标下满足 `X = −2Y²`（≤1.4e-15）、`V = −X²/4`（≤5.2e-31）、**最大 X = 0** ⇒ 就是**半支抛物线**；

## 6. 对 GPT 文本的（非致命）异议：符号记账

A4 里 `k=(r−r_c(z))·sqrt(|K(z,r)|)`、`ε1(a+sY²)²`、`K 在原点非零、同号` 这几处把**绝对值与符号**混在一起了。严格写法（我在 exp62 里实现的就是这套）：

* `G = (H − H_c)/(r−r_c)²` 在邻域内非零 ⇒ 取**解析**平方根 `K`；当 `C₀ < 0`（`A0=C2` 那两点）时 `K(z₀,0)` 是**纯虚数**，不能用 `sqrt(|K|)`；此时应改用 `k = √(−(H−H_c))`、`ε₁ = −1`，其余不变；
* `σ = sign b`（本臂四点恒为 +1），`X = 2σa`、`Y = y√|b|`，`k = a + σY²` 才是恒等式。

按这套写法四个点全部成立；**结论不变**，只是原式在 `C₀<0` 的两点上不能按字面读。
