# exp73：移动中心与公共参数保留，独立小段探索

## 结论与范围

本轮自行实现、运行并复算了根 13 的移动中心管。保持 exp69 精确模型、Fraction 区间后端以及原来的 `κ<1/2`、逐行相对余量 `>=1/4`，在 a 环首边上认证了从基点出发、长度 **2^-14 = 6.103515625e-5** 的一个参数段。首片严格包含 C1 根 13 的认证盒，故这是真实已编号根的连续正则提升，不只是附近某个解的存在性。

这是局部改进，不是完整边、完整回路、六根批量或置换认证。没有升级固定臂不可解性的证明等级。本轮继续使用既有 Fraction 算术；新的内容是围界数学和独立实现，不是独立算术后端。

## 为什么此前的界还能大幅收紧

只改为移动中心但把整个扫掠盒直接交给自然区间运算，仍然会丢掉一个共同路径参数带来的相关性。对同一个扫掠盒，exp73 比较了两种 Jacobian 界：

| 参数长度 L | 横向半径 r | 新 κ 上界 | 自然 W 区间 κ 上界 | 最小相对余量 | 本方法认证 |
|---|---|---:|---:|---:|---|
| 2^-23 | 2^-35 | 0.000214014 | 0.0156546 | 0.798608 | 通过 |
| 2^-20 | 2^-29 | 0.00171920 | 0.125275 | 0.790244 | 通过 |
| 2^-17 | 2^-22 | 0.0143050 | 1.00774 | 0.853857 | 通过 |
| 2^-14 | 2^-15 | 0.164722 | 8.78921 | 0.658930 | 通过 |
| 2^-12 | 2^-9 | 4.87765 | 82.7443 | -4.01362 | 不通过 |

自然 W 界是在**同一个逐坐标扫掠包络**上评价，不是把旧固定中心算法的结果误贴过来。2^-12 的失败只是这一组充分判据不通过，不表示路径奇异；该候选的 trace 界也超过 4。

最长通过段还有：`|trace S-3| <= 1.922961 < 4`，各坐标 `|z_j|²` 的下界最小为 0.272970；基点盒严格包含于首片，最小包含余量约 2.90023e-5。原始精确有理数全部保存在 JSON 中。

## 新围界的证明

写 `lambda=i*(h+s)`，`-h<=s<=h`，`L=2h`，预测中心 `c(s)=c0+s*v`。c0、v、B 均由数值计算选取后冻结为精确二进有理数。令 z 是六个复变量，横向误差 e 的十二个实分量都满足 `|e_k|<=r`。

沿用 W 预条件多项式

    W_ij(z) = sum_k (B[i,2k]-i*B[i,2k+1])*J_kj(z).

其实际实化矩阵条目为 `Re W_ij` 和 `-Im W_ij`。记 C 为预测中心线的矩形包络，X 为中心线加横向盒的包络，`D_v W=sum_k v_k*partial_k W`。分开路径移动与横向误差，积分中值公式给出

    W(c0+s*v+e)
      ∈ W(c0) + [-h,h]*D_v W(C)
                + sum_k partial_k W(X)*([-r,r]+i[-r,r]).

证明分两段积分：先从 c0 沿共同参数走到 c0+s*v，再沿直线走到 c0+s*v+e。第一段的求和在 Laurent 系数层面先组合，**不把各坐标的路径变化当成相互独立**。第二段允许更保守的矩形包络。由这些区间构造 `I-B Df` 的逐行绝对值和，即得到新 κ。

对预条件中心残差，令 `P_i=sum_k(B[i,2k]-i*B[i,2k+1])*F_k`。其真实第 i 个分量是 `Re P_i`。路径目标平移关于 s 是仿射的，因此用精确点残差、精确一阶预测缺陷和中心线上的二阶方向导数界：

    eta_i = |(B f(c0,lambda_mid))_i|
          + h*|(B(Df(c0)*v-b))_i|
          + h²/2 * sup_C |Re D_v² P_i|.

实现并未把浮点求得的切线当成精确解；中间的一阶缺陷完整保留。检查 `eta_i/r + κ_i <= 3/4` 与 `max κ_i<1/2`，再检查极点和 trace 排除，得到每个切片的严格收缩。首片包含已认证 C1 盒，建立根身份。

## 实测成本：区分步长与端到端效率

从磁盘 `chunk_13_0.json` 提取旧方法的**第一管**，用当前精确模型重新计算，旧管通过，η、κ、相对余量、trace_bound 逐项完全相同。

* 旧管长度约 1.1622440e-7；本轮通过长度为其约 **525 倍**。
* 旧管 `tube_record` 本次求值约 **1.54 秒**，不含其预先构造 W 的成本。
* 新管主梯度运行每段约 **17.5–20.1 秒**，含构造 W、方向导数、额外自然界比较与入口包含检查。
* 以最长通过段的 17.93 秒估算，两次局部计时对应的“长度/求值秒”约改善 **45 倍**。负载、缓存和计时范围不完全相同，且没有计入长链节点/拼接成本，不能当作整环加速倍数或工期保证。

因此，先重写底层或先压缩 270 GB 并非唯一合理顺序。这个结果说明数学表示仍有显著空间。但沿环各位置的界、trace 排除及六根成本都需要另测，不能按首段乘长得到认证预算。


验证器从保存的中心、速度、B、半径重算所有有理界及入口包含，比较每个字段，绑定模型、C1 证书、归档路径和所用实现的 SHA256；拒绝空梯度、错误根编号、非法段长和维数。这里是实验结果复算器：一个如实记录的“不通过”候选也应复算成功，而不是被伪装成通过。

有意义的负对照：将通过段的预测速度**反向**，保留中心、B 和原半径，重新运行真正的不等式，必须得到负相对余量并拒绝认证。另有复方向二阶导数的精确回归（1/z，v=1+i，z=2，二阶导数=i/2）、扫掠盒包含检查、非法参数长度拒绝测试。

旧管快照和本次复算值另存 `exp73_fixed_baseline.json`，不依赖未入 git 的大 chunk 保持可读性。新实验 JSON 约 779 KB，未做压缩研究。
