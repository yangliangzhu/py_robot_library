## A. 3R：从原 FK 到源奇点的精确分类

### A1. 原 FK，不使用 exp54 消元系数

令 u=q2、v=q3。按 `cuspidal3r.DEFAULT_ROWS/DEFAULT_TOOL` 的精确直角 MDH 矩阵相乘，q1=0 时得到：

```
A = 2 sin u + (3/2) sin v cos u
px = 1+A
py = (3/2) cos v - 1
z  = (3/2) sin u sin v - 2 cos u
R  = ρ² = px²+py²
A²+z² = 4+(9/4)sin²v
det D_(u,v)(R,z) = -3 sin v * (A+(3/2)cos v).
```

q1 只是绕世界 z 轴旋转。ρ>0 时可用目标方位角作为一个正则坐标，因此三维位置映射的局部分类等于上述二维映射乘一个恒等方向。两组候选处 ρ 均非零。

### A2. 四个目标点的全部源构型（模 2π）

令 S=R+z²、w=cos v。从上式直接消去 A 得到必要等式：

```
18w² + 6(S-33/4)w + (S-33/4)² + 4z² - 25 = 0.
```

在 `(R,z²)=(1/2,7/4)` 化成 `18(w-1)²=0`；在 `(25/2,7/4)` 化成 `18(w+1)²=0`。故：

| 目标 | v | sin u | cos u |
|---|---|---|---|
| R=1/2，z=±√7/2 | 0 mod 2π | −3/4 | −z/2 |
| R=25/2，z=±√7/2 | π mod 2π | +3/4 | −z/2 |

代回原 FK 成立。u 模 2π 唯一；指定非零水平目标向量后 q1 模 2π 也唯一。这里是原 FK 的纤维结论，不是把消元四重根直接解释成四个源点。

### A3. 用正则输出 z 作为源坐标

上述点 z_u=2 sin u=∓3/2 非零，所以 `(u,v)→(z,v)` 是局部微分同胚。选取局部平方根正支，有精确表达式：

```
R = 33/4-z² + 2ε sqrt(4+(9/4)sin²v-z²) - 3cos v,
```

第一组 ε=−1，第二组 ε=+1。令 y=v（第一组）或 y=v−π（第二组），则：

```
R(z,y)-R(z,0) = B(z)y² + C0 y⁴ + O((z-z0)y⁴,y⁶).
```

精确系数如下：

| 组 | B(z) | B'(z0) | C0 |
|---|---|---|---|
| 第一组 | 3/2−9/(4√(4−z²)) | −2z0/3 | +3/4 |
| 第二组 | −3/2+9/(4√(4−z²)) | +2z0/3 | −3/4 |

四点均满足 B(z0)=0、B'(z0)≠0、C0≠0，且局部表达式对 y 严格为偶函数。

### A4. 精确正规形，而不只是四阶 jet

以 `r=y²` 为中间变量，因偶解析性可写成 `R=H(z,r)`。在候选点：

```
H_r=0,  H_rr=2C0≠0,  H_zr=B'(z0)≠0.
```

由隐函数定理存在 H_r(z,r_c(z))=0，且 `r_c'(z0)=−H_zr/H_rr≠0`。Taylor 因式分解给出

```
H(z,r)-H(z,r_c(z)) = ε1 * k(z,r)²,
```

其中 `k=(r-r_c(z))*sqrt(|K(z,r)|)`，K 在原点非零、同号，`k_r≠0`。定义 `a(z)=k(z,0)`，则 a(z0)=0 且 a'(z0)≠0。又有

```
k(z,y²)=a(z)+y² b(z,y²),  b(z0,0)≠0.
```

取新的源坐标 `Y=y sqrt(|b(z,y²)|)`，目标与源的第一坐标同时改成 a(z)，减去仅依赖第一坐标的目标函数并缩放，即得到精确实解析左右等价正规形：

```
(X,Y) → (X, Y⁴+X Y²).
```

具体地，平方项是 `ε1(a+sY²)²`，减去 `ε1 a²`、除以 ε1、把第一坐标改为 X=2s a 即得上式。各变换局部可逆。

原三维位置映射因此局部等价于 `(θ,X,Y)→(θ,X,Y⁴+XY²)`。

这个正规形的临界集是 `Y=0` 与 `X=−2Y²` 两条横截的光滑源曲线；其临界像分别为 `V=0` 与 `V=−X²/4`。后者的**实**像只取 X≤0 的半支。完整复解析临界像（或实像的解析闭包）呈 tacnode；实际可达边界需保留这个半支限定。

普通 cusp 正规形 `(X,Y³+XY)` 的临界集是一条光滑曲线，而这里的临界集有横截交叉，故这四个源点不是普通 cusp。原点的局部代数商为 `R{Y}/(Y⁴)`，重数为 4。

**范围**：这完成四个给定候选的源点局部分类，不宣称整台臂所有其他点都没有 cusp，不取消已有 cuspidality 数值见证。也不把“四阶”自动称为普通 swallowtail。可与 [Kabata 的平面映射芽识别研究](https://eprints.lib.hokudai.ac.jp/dspace/bitstream/2115/65334/1/Yutaro_Kabata.pdf) 对照术语；本结论依据以上显式坐标变换，不依赖给它选一个名称。

## B. 只用连杆长度给出严格 L 界

### B1. 假设与记号

实串联 nR 臂，固定刚体连杆、固定基座和工具，空间几何 Jacobian `J=[Jv;Jω]`。第 j 关节的世界单位轴为 e_j，轴上一点 o_j，工具点为 p：

```
Jv_j = e_j × (p-o_j),    Jω_j=e_j.
q(t)=q0+t*d, 0≤t≤1.
```

选择任何全局上界 `ell_j ≥ ||p-o_j||`。库的 Ms 布局中可以取从关节 j 之后到末端的固定平移长度之和：第 j+1…n 连杆平移范数，加工具平移范数。关节 j 自己之前的平移不计入。固定旋转不改变长度。

如果要完全使用有理上界，可用每个固定平移向量的 l1 范数代替 l2 范数。base 的固定旋转不影响该界。

定义：

```
a_j = Σ_(k<j) |d_k|
b_j = a_j*ell_j + Σ_(k≥j) |d_k|*ell_k.
```

则对全段每一点：

```
||dJv_j/dt||₂ ≤ b_j,
||dJω_j/dt||₂ ≤ a_j.
```

### B2. 证明

上游关节 k<j 同时旋转 e_j 和相对向量 r_j=p-o_j。叉乘的旋转等变性给出

```
∂_(q_k)(e_j×r_j) = e_k×(e_j×r_j),  k<j,
```

其范数≤ell_j。下游及本关节 k≥j 不改变 e_j、o_j，只改变 p，因此

```
∂_(q_k)(e_j×r_j) = e_j×[e_k×(p-o_k)],  k≥j,
```

其范数≤ell_k。轴方向仅受上游旋转影响，`||∂_(q_k)e_j||≤1`（k<j），其余为零。沿 d 求方向导数并用三角不等式即得。

这给出解析全局界，既不是有限差分最大值，也无需先计算 Hessian。

### B3. 单位缩放与整段认证

对固定正数 α,β，令 `Jbar=diag(α I3,β I3)J`。可取

```
L = sqrt(Σ_j (α² b_j²+β² a_j²)),
||dJbar/dt||₂ ≤ ||dJbar/dt||F ≤ L.
```

更保守的免平方根上界是 `L1=Σ_j(α b_j+β a_j)`。对只做位置任务的 3R，删去角速度项即可。此处不把该界用于复关节：复旋转不再是实正交等距变换。

若采样点覆盖 [0,1] 的最大距离为 h，且每个采样都有**经认证的**奇异值下界 s_k，则

```
σ_min(Jbar(q(t))) ≥ min_k s_k - L*h.
```

含两端点的等距 N 个采样，h=1/[2(N−1)]。中点单样本也可用 h=1/2。该界可能保守，但自适应缩短关节段会使 L 按段位移线性缩小。

### B4. 不能遗漏采样点的浮点误差

普通浮点 SVD 不能直接当严格 s_k。对方阵 Jbar，取数值近似逆 B，把 B 的浮点元素作为精确二进制有理数；用外向舍入的区间 FK/Jacobian 评价矩阵残差。若得到

```
||I-B Jbar||₂ ≤ e < 1,
||B||₂ ≤ M,
```

则 `s_k=(1-e)/M` 是严格下界。e、M 可使用较保守的 Frobenius 范数上界（或更保守的元素绝对值和）。证明：`||BJbar x||≥(1-e)||x||`，同时 `||BJbar x||≤M||Jbar x||`。

所以完整实现需要：明确的精确几何模型、区间 sin/cos、外向舍入残差、上界 L、细分与限位检查。普通 NumPy 实现只可标“解析界 + 浮点验证”，不能标“机器认证”。绕环面短路必须保存实际选定的连续角度提升，并检查该提升是否符合物理限位。

## C. 固定 SR5 复位姿回路：具体平方系统

已阅读 `study/monodromy.py`，接受 DeepSeek 的补充：固定参数的**实位姿**仪器已有，需补的是复位姿与对应方程/根身份认证。

### C1. 合法的复位姿坐标

在复 SO(3) 的 Cayley 图中使用三个坐标 w，

```
R(w)=(I+[w]×)(I-[w]×)^(-1),
chi(R,p)=(p, vee((R-I)(R+I)^(-1))).
```

排除分母为零处。需要时对 R 先乘一个固定基准旋转的逆，把 T0 移进图；矩阵的复旋转约束是 RᵀR=I，不是 R*R=I。

取一条直线 `tau(λ)=tau0+λ d`，通过图逆映射得到合法 T(λ)。第一版可只令 d 的平移部分非零；姿态保持固定。若该切片没有足够置换，换方向，而不是改变机械参数。

用关节 Laurent 变量 z_j∈C* 构造平方系统：

```
G(z,λ)=chi(F_SR5(z))-tau0-λd = 0    （六方程、六根变量）.
```

也可暂用复角度作数值局部坐标，但根比较最好转到 z=exp(iq)，从表示层面消除 2π 别名。清分母时须剔除分母零点、z_j=0 的伪根。该坐标图不覆盖所有位姿；失败应明确是图极点、路径跟踪失败还是根事件。

### C2. 求切片简单分支点

未知 `(z∈C^6, λ∈C, v∈C^6)`，给定一般常向量 c：

```
G=0,  G_z v=0,  cᵀv=1.
```

这是 13 个复方程、13 个复未知量。解出后检查 rank G_z=5，并找左零向量 lᵀG_z=0。简单 fold 的充分局部非退化检查为

```
lᵀG_λ ≠ 0,
lᵀD_z²G[v,v] ≠ 0.
```

这里是复代数的双线性转置；不能把左零向量与 Hermitian 内积不加区分。满足时局部平方根分裂提供一对根的交换。

**重要限制**：某个源点是简单 fold，不保证同一目标处没有另一个源 fold。若多个临界源点共享目标，小回路可能同时产生多对交换。必须保留完整置换，不能从一对的局部检测擅自生成独立对换。

另一种便宜的起点：先在固定臂关节空间找 rank=5 的 q*，算 T*=FK(q*)，再选横截其临界像的目标方向；局部分裂可先于全纤维普查验证。后续统一运输回共同基点，才有群生成元的统一编号。

### C3. 最小成果与失败条件

沿用任务 T4 的共同基点、逆向返程、全根身份与负对照要求。先拿一个可靠的固定臂复回路，不立即追求 S16。严格认证非可解子群后即可结束根式不可解性的证明工作；完整群是另一个问题。

## D. 顺手发现的群论注意事项

`monodromy.py` 开头声称“5-cycle 加 double transposition 就生成 A5”，这缺少生成元相对位置条件。例如

```
r=(0 1 2 3 4),  s=(1 4)(2 3)
s r s = r^(-1)
```

二者生成阶 10 的二面体群，是可解群，而不是 A5。本轮显式闭包亦得到 10；下面可独立重放：

```bash
python3 - <<'PY'
r, s = (1,2,3,4,0), (0,4,3,2,1)
seen = {tuple(range(5))}
todo = list(seen)
while todo:
    p = todo.pop()
    for g in (r, s):
        h = tuple(p[g[i]] for i in range(5))
        if h not in seen:
            seen.add(h)
            todo.append(h)
print(len(seen))  # 10
PY
```

请用实际完整置换闭包/可解性判定，不能只按 cycle type 裁决。

类似地，嵌套平方根的根式公式一般只保证可解，不能由“三次 ± 选择”直接推出整个群为初等阿贝尔 2-群。例如 `x⁴=t` 可用两层平方根求解，但在 C(t) 上群是 C4，绕 t=0 一圈产生四循环，并非 C2×C2。SR0 是否更特殊，应检查平方根域之间的依赖。此处仅指出推理规则不足，不替代 Q8 的具体计算。
