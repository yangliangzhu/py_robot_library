## R15. K-3：全纤维 16 根 + fold→对换表 + 对换图分析

命令：`python3 -m study.exp38_monodromy_group`（fold 谱重算 + s=1 全纤维 + 逐 fold 追踪匹配）

**phase A — s=1 全纤维（16 根，达到 Raghavan-Roth 上限）**：

* 实根 10 个（普查 400 种子 + 环面去重 + 物理可达过滤；与 exp25 的计数序列终点一致）；
* 复根 6 个：三对消亡 fold 的根对从实侧出发、**绕各自 fold 走上半平面小弧**、
  复牛顿追踪到 s=1（全部 ok，残差 ~1e-15，|imag| 0.15 / 0.60 / 0.91 三对共轭）。
  仪器教训（第五条，已修）：**实牛顿过不了 fold 合并点**（全部停在残差 ~1e-3 处、
  解保持实数）—— 必须绕复弧；弧线侧（上半平面）是约定，保持一致即可。

**phase B — fold → 对换表**（每条边 = 该 fold 的合并根对在基纤维上的下标对）：

| fold s* | 类型 | 对换 | | fold s* | 类型 | 对换 |
|---|---|---|---|---|---|---|
| 0.655086 | 诞生 | (10, 0) | | 0.718354 | 消亡 | (10, 11) |
| 0.656878 | 诞生 | (13, 7) | | 0.799244 | 消亡 | (12, 13) |
| 0.657375 | 诞生 | (9, 14) | | 0.961848 | 消亡 | (14, 15) |
| 0.658119 | 诞生 | (1, 8) | | | | |

**phase C — 对换图（7 边、16 根）**：连通分量大小 **[3, 3, 3, 2, 1, 1, 1, 1, 1]**。

* 结构观察：三个消亡 fold 各自把一个诞生 fold 的轨道**延长一格**（{0,10,11}、{7,12,13}、
  {9,14,15}），诞生 0.658119 自成 {1,8} —— 诞生↔消亡共用根，谱系结构清晰可见。
* 群结论：测得的子群 ≅ S3 × S3 × S3 × S2（每轨道内对换生成全对称群），**可解**。
  **对"无根式解"尚无结论**：这只是 s 单参数切片的 7 个 fold —— 判别式的其余部分
  （二维切片的 cusp 环、其它分支点）还会贡献生成元。下一步见 day06-kimi.md §2。

## R16. K-1：见证路径的投影绕的是"无"（第一个测量）

命令：`python3 -m study.exp39_witness_projection`（pair (5,3)，exp19 pose 0）

* 直线两个真穿越精化到 det J ~ 1e-17；其像 FK = (−0.1293, −0.0723) 与 (−0.1340, −0.0736)，
  **相距仅 5 mm**；
* 见证路径（132 点）投影：基点 (−0.1385, −0.0760)，环 extent x ∈ [−0.2455, −0.1228]、
  y ∈ [−0.0966, 0.0982]（12 cm × 19 cm 的大环）；
* **环绕数：绕两个 fold 像均为 0.00**；最近接近 5~10 mm，该处 det J = −1.3e-3 ≠ 0
  （正则原像 = 特征曲面穿越，与"路径不穿 Σ"自洽）。

读法：该环在 (x,y) 切片里不环绕任何可见结构 —— 与"无 cusp 的绕行"和"cusp 在切片外"
都相容；区分两者需要**本位姿**的 fold 曲线图（当前只有 exp21 位姿的）。
